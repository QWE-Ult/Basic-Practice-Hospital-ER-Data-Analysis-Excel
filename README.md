# Hospital ER Data Analysis - Excel

## About the Project

This is one of my basic Excel data analysis projects.

I used hospital emergency room data and tried to find some useful information from it, like:

* Total number of patients
* Number of admitted patients
* Admission rate
* Average waiting time
* Average satisfaction score
* Patients by department
* Patients by age group
* Monthly patient data

## Data

The dataset has around **9,216 patient records**.

Some of the columns in the data are:

* Patient ID
* Admission Date
* Gender
* Age
* Race
* Department Referral
* Admission Flag
* Satisfaction Score
* Wait Time

## What I Did

First, I cleaned the data and added a few extra columns like:

* Admission Status
* Age Group
* Wait Time Category
* Month

Then I used Excel formulas to do some calculations and analysis.

I also created some charts and a simple dashboard to show the results.

## Excel Functions I Used

Some of the Excel functions I used in this project are:

* COUNT
* COUNTA
* COUNTIF
* COUNTIFS
* AVERAGE
* AVERAGEIF
* IFERROR

## Dashboard

The dashboard shows things like:

* Total Patients
* Admitted Patients
* Admission Rate
* Average Wait Time
* Average Satisfaction
* Patients by Department
* Monthly Patient Count
* Patients by Age Group
* Admitted vs Not Admitted
